Track 1: RAG

Build a RAG system that answers questions from a single source of truth: lecture content on Data Structures and Algorithms (DSA).

Source of truth (pick one lecturer)

  • Erik Demaine
  • Virginia Vassilevska Williams

What you need to do

  1. Choose a topic. Pick any DSA topic of medium difficulty. Quick Sort, Heap Sort, or anything at that level or above is fine.
  2. Create the content. Prepare material for your chosen topic, based on the lecturer's lectures.
  3. Create the RAG. Build a RAG pipeline that uses only that content as its knowledge base, so every answer is grounded in the source.
  4. Deploy it. Put the RAG on an interface hosted on Hugging Face, for example a Hugging Face Space.
  5. Prepare the deliverables.
    • A slide deck
    • A video animation with voice-over
    • The voice-over should be in a local language (or another language you choose).
Deadline: Monday, 1:00 PM
